Work through Intensity Transformations and Neighborhood Filtering one question
at a time. The current notebook covers Questions 1 and 2.

## Open the notebook

From this directory in PowerShell:

```powershell
.\.venv\Scripts\python.exe -m jupyterlab assignment_01.ipynb
```

The local `.venv` uses Python 3.11 and the packages already installed on this
computer. Select that environment as the notebook kernel.

For a clean setup on another Windows computer with Python 3.11 installed:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m ipykernel install --prefix .venv --name en3160 --display-name "Python 3 (EN3160)"
.\.venv\Scripts\python.exe -m jupyterlab assignment_01.ipynb
```

The notebook contains its own implementation, explanations, checks, image
comparisons, and discussion. Run cells from top to bottom. Adjust the
`EXPERIMENTS` breakpoint lists to try other Question 1 transformations. For
Question 2, adjust `WM_BREAKPOINTS` and `GM_BREAKPOINTS` to change the intensity
bands used to emphasize white and gray matter in the brain image.
